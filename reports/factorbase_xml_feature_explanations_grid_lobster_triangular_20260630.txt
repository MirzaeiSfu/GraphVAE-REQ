How to read these XML files
---------------------------
- Each <VARIABLE> is a FactorBase random variable. Names like distance_to_boundary(nodes0) and distance_to_boundary(nodes1) are the same feature attached to the two node aliases in an edge tuple.
- Each <OUTCOME> is an allowed categorical value. The XML stores integer-like category IDs, not long labels.
- Each <DEFINITION> gives the conditional probability table (CPT) for one variable. <GIVEN> entries are the learned parent variables.
- The first CPT example below is the probability vector for the child variable when every parent is in its first listed outcome. For variables with no parents, it is the marginal/prior distribution.
- edges(nodes0,nodes1) has only outcome T in these files, so all CPTs are learned over observed/positive edge rows.
